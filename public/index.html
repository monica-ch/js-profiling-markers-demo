The JS Self-Profiling API lets a page profile its own JavaScript with a sampling profiler. The markers extension (currently in Origin Trial) adds a marker field to each sample telling you what the user agent was doing when the sample was taken — script, gc, style, layout, or paint.

Exposure is gated on cross-origin isolation: stylelayout are available everywhere; scriptgcpaint require a cross-origin-isolated (COOP+COEP) document.
